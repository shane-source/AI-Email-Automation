📧 AI Email Automation Agent

An AI-powered email assistant built using n8n, Google Gemini, and Gmail that automates email generation and communication through natural language instructions.

🚀 Project Overview

This workflow allows users to interact with an AI Agent through a chat interface and automatically generate and send emails using Gmail.

Instead of manually writing emails, users simply provide instructions in plain English, and the AI handles the rest.

Example

User Input

Send a professional follow-up email to a client who attended our product demo yesterday.

AI Output

Generates a professional email and sends it automatically through Gmail.
